# CodingTest · 알고리즘 및 SQL 풀이

백준·프로그래머스·SWEA 문제 풀이를 기록한 저장소입니다. Java 풀이를 중심으로 관리하며, SQL과 Python·JavaScript 풀이도 포함되어 있습니다.

| SWEA | 난이도별 문제 | [SWEA](SWEA/) |

## 저장 구조

플랫폼 → 난이도 또는 레벨 → 문제 번호·이름 순서로 저장되어 있습니다.

각 문제 폴더에는 문제 설명을 담은 `README.md`와 풀이 코드가 있습니다. 폴더명에서 문제 번호나 이름을 검색하면 해당 풀이를 찾을 수 있습니다.
